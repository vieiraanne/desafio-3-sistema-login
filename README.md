# 🔐 Desafio 3 – Sistema de Login e Perfil

## 📌 Sobre o projeto
Este projeto foi desenvolvido como parte de um desafio prático de programação, utilizando PHP e banco de dados MySQL. O objetivo é criar um sistema de login que permita aos usuários acessar uma área restrita, visualizar seu perfil e personalizar a aparência da página.

## 🎯 Objetivo
Desenvolver um sistema de autenticação de usuários, colocando em prática os conhecimentos sobre PHP, sessões, conexão com banco de dados e desenvolvimento de páginas web.

## ⚙️ Funcionalidades

- **Login de usuário:** permite que o usuário entre no sistema utilizando os dados cadastrados no banco de dados.
- **Validação de acesso:** verifica se as informações de login estão corretas antes de permitir a entrada.
- **Sessões PHP:** utiliza sessões para manter o usuário autenticado durante a navegação.
- **Página de perfil:** exibe uma página exclusiva para usuários que realizaram o login corretamente.
- **Personalização:** permite alterar a cor de fundo da página de perfil.
- **Logout:** disponibiliza uma opção para sair do sistema, encerrando a sessão do usuário.
- **Proteção de páginas:** impede que usuários não autenticados acessem diretamente a página de perfil.

## 💻 Tecnologias utilizadas
- PHP – desenvolvimento das funcionalidades e controle de sessões.
- MySQL – armazenamento dos dados dos usuários.
- HTML – estruturação das páginas.
- CSS – estilização e personalização visual.

## 🔒 Segurança
O sistema utiliza sessões PHP para controlar o acesso às páginas restritas, garantindo que somente usuários autenticados possam visualizar o perfil. Também realiza a verificação dos dados informados no login.

## 📚 Conhecimentos praticados
Durante o desenvolvimento do projeto, foram praticados conceitos importantes de programação, como conexão com banco de dados, consultas SQL, autenticação de usuários, manipulação de sessões e personalização de páginas com PHP.

## ✅ Conclusão
O desafio permitiu desenvolver um sistema de login e perfil completo, colocando em prática os conhecimentos adquiridos nas aulas de PHP e MySQL. Além disso, possibilitou compreender a importância da autenticação e do controle de acesso em sistemas web.
