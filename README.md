 README - Sistema de Login

Este projeto é um sistema de login desenvolvido com **HTML, PHP e MySQL**.

 Funcionalidades
- Formulário para inserir usuário e senha.
- Verificação dos dados no banco de dados.
- Redirecionamento para uma página restrita após o login.
- Exibição de mensagem de erro quando os dados estão incorretos.
- Utilização de sessões para controlar o acesso.

 Tecnologias utilizadas
- HTML
- PHP
- MySQL

 Objetivo
O objetivo do projeto é praticar a integração entre PHP e MySQL, permitindo a autenticação de usuários e o acesso a páginas restritas.
